# Quick Start: Oglot + Jupyter in Doom Emacs

## Installation (5 minutes)

### Step 1: Update Config Files

Replace your `config.org` and `packages.el` with the corrected versions provided.

### Step 2: Sync Doom

```bash
doom sync
```

### Step 3: Restart Emacs

Either:
- Restart Emacs completely, OR
- Run `M-x doom/reload`

### Step 4: Verify Installation

```
M-x +oglot/verify-setup
```

Should show:
```
Oglot enabled modes: (python-mode)
org-babel-edit-prep:python: defined
Jupyter override: active
```

```
M-x +jupyter/verify-setup
```

Should show:
```
ob-jupyter loaded: t
python->jupyter override: YES
Default session: py
Default kernel: python3
```

## Your First Jupyter+LSP Block (2 minutes)

### Create Test File

Create `test-jupyter-lsp.org`:

```org
#+TITLE: Test Jupyter + LSP Integration

* Setup

#+begin_src python :tangle /tmp/test-analysis.py :comments link :session test
import pandas as pd
import numpy as np

def load_data():
    """Load sample data."""
    return pd.DataFrame({
        'a': [1, 2, 3, 4, 5],
        'b': [10, 20, 30, 40, 50]
    })

def analyze(df):
    """Compute basic statistics."""
    return df.describe()
#+end_src

* Analysis

Now let's use our functions:

#+begin_src python :tangle /tmp/test-analysis.py :comments link :session test :results output
df = load_data()
stats = analyze(df)
print("Dataset Statistics:")
print(stats)
#+end_src
```

### Test Jupyter Execution

1. Place cursor in the first block
2. Press `C-c C-c`
3. ✅ Should execute (no output since we're just defining functions)

4. Place cursor in the second block
5. Press `C-c C-c`
6. ✅ Should see statistics printed below

### Test LSP Features

1. Place cursor in the first block
2. Press `C-c '` (that's C-c followed by single quote)
3. ✅ You're now in an org-src buffer
4. ✅ You should see "Eglot" in the modeline
5. Start typing `df.` and you should see completions
6. Hover over `pd` to see "pandas module" documentation
7. Press `C-c '` again to return to org file

## Usage Patterns

### Pattern 1: Quick Exploration (Jupyter Only)

```org
#+begin_src python :session explore
import numpy as np
arr = np.random.rand(10)
print(arr.mean())
#+end_src
```

**Use**: Quick calculations, no LSP needed
**Command**: `C-c C-c` to execute

### Pattern 2: Library Development (LSP Only)

```org
#+begin_src python :tangle ./src/utils.py :comments link
def helper(x: int) -> int:
    """Double the input."""
    return x * 2
#+end_src
```

**Use**: Building reusable functions
**Command**: `C-c '` to edit with LSP

### Pattern 3: Data Analysis (Both!)

```org
#+begin_src python :tangle ./analysis.py :comments link :session main
import pandas as pd

def load_and_process(path: str) -> pd.DataFrame:
    """Load CSV and clean data."""
    df = pd.read_csv(path)
    return df.dropna()

# Test it
df = load_and_process('data.csv')
print(f"Loaded {len(df)} rows")
#+end_src
```

**Use**: Development + immediate testing
**Commands**: 
- `C-c '` to develop with LSP
- `C-c C-c` to test with Jupyter

## Essential Keybindings

### In Org Mode

| Key | What It Does |
|-----|-------------|
| `C-c C-c` | Execute block with Jupyter |
| `C-c '` | Edit block with LSP |
| `SPC j c` | Toggle `:comments link` |
| `SPC j v` | Verify Jupyter setup |
| `SPC j o` | Verify oglot setup |

### While Editing (`C-c '`)

| Key | What It Does |
|-----|-------------|
| `C-c '` | Save and exit |
| `SPC m k` | Abort without saving |
| `TAB` | Auto-complete |
| `SPC c h` | Show documentation |
| `SPC c d` | Go to definition |
| `SPC c r` | Rename symbol |
| `SPC c a` | Code actions |
| `SPC c =` | Format code |

## Common Issues & Quick Fixes

### "No LSP features when editing"

**Fix**: Add `:tangle` to your block:
```org
#+begin_src python :tangle ./code.py :comments link
...
#+end_src
```

### "Jupyter not executing"

**Fix**: Check override is active:
```
M-x +jupyter/verify-setup
```

If it says "NO", restart Emacs.

### "org-babel-edit-prep:python not found"

**Fix**: Make sure you're using the corrected config.org, then:
```bash
doom sync
M-x doom/reload
```

## Project Setup Template

For a new data analysis project:

```
my-analysis/
├── analysis.org         # ← Create this
├── src/
│   └── (tangled files go here)
└── data/
    └── dataset.csv
```

**analysis.org:**
```org
#+TITLE: My Analysis
#+PROPERTY: header-args:python :tangle ./src/analysis.py :comments link :session main

* Import Libraries

#+begin_src python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
#+end_src

* Load Data

#+begin_src python
def load_data(path):
    return pd.read_csv(path)

df = load_data('data/dataset.csv')
#+end_src

* Analysis

#+begin_src python :results output
print(df.describe())
#+end_src
```

Then:
1. `C-c '` on any block → develop with LSP
2. `C-c C-c` on any block → test with Jupyter
3. `C-c C-v C-t` → tangle entire file

If something doesn't work:

1. Run verification commands:
   - `M-x +oglot/verify-setup`

2. Check `*Messages*` buffer: `C-h e`

3. Check Eglot events: `M-x eglot-events-buffer`

4. Consult the full usage guide (provided separately)

5. Check the integration summary (explains the fix)
